# 训练稳定性评测方案

> 本项目的验收核心。目标不是"跑出一个好数字"，而是**可靠地回答：AgentOPSD 在 8B 上训练稳不稳定、为什么、如何复现**。

## 1. 稳定性的定义

在固定数据、固定超参、固定硬件规模下，满足以下全部条件即判定为"稳定"：

1. **收敛**：验证成功率随时间单调上升并进入平台期（允许小波动，不允许持续下滑）。
2. **无发散**：全程无 NaN/Inf，loss、优势、梯度范数量级可控（无 >1e4 的异常尖峰）。
3. **熵不崩塌**：策略熵缓慢下降但不塌到 0（保留探索），teacher–student gap 不振荡发散。
4. **可复现**：同配置不同 seed 的成功率终值与曲线形状接近（±3 分以内）；同 seed 复跑一致。
5. **续训一致性**：训练中途杀掉，用断点续训，续训曲线与连续训练曲线无缝衔接（同一步的指标差 < 1%）。
6. **规模鲁棒性**：2 卡与 4 卡训练行为一致（吞吐不同，指标曲线可比）。

## 2. 观测指标

### 2.1 训练与验证指标（verl 自带，console/wandb）

| 指标 | 含义 | 预警规则 |
|---|---|---|
| `val/success_rate` | 验证集成功率 | 连续 10 步下滑 > 5 分；或末期振荡幅度 > 10 分 |
| `actor/entropy_loss` | 策略熵 | 降至 < 0.01 或相对初值崩 90% 以上 |
| `actor/policy_loss` / `actor/kl_loss` | 策略/ KL 损失 | NaN；或量级突变 > 10× |
| `actor/global_grad_norm` | 梯度范数 | 持续 > 10 或出现单步尖峰 > 100 |
| `val/...` 各子类 | ALFWorld 六类任务成功率 | 任一类长期为 0 且另一类异常高（分布失衡） |

### 2.2 AgentOPSD 信用诊断（`[agentopsd]` JSON 行）

| 指标 | 含义 | 关注点 |
|---|---|---|
| `agentopsd/evidence_abs_mean` | 每轮平均 |证据绝对值 | 训练早期应 > 0（teacher 有信息量），后期自然变小 |
| `agentopsd/belief_revision_abs_mean` | 平均 |ΔB| | 反映信用分辨率；长期为 0 说明 gap 无信号 |
| `agentopsd/credit_abs_mean` | 平均 |q| | 与优势尺度配合看整形是否生效 |
| `agentopsd/multiplier_min/max/mean` | 乘子 w 范围 | 应稳定在 [1−b, 1+b] 内；长期贴边说明标准化异常 |
| `agentopsd/pivotal_turn_ratio` | |z|>1 的轮次占比 | 过高（>0.5）说明信用过度集中，过低（<0.1）说明整形趋近 GRPO |
| `agentopsd/adv_std_before/after` | 整形前后优势 std | after 应比 before 大（信用被拉开），但不应差 10× 以上 |
| `agentopsd/turns_per_traj_mean` | 平均轨迹轮数 | 用于按 horizon 分层分析（对齐论文 Figure 1b） |

## 3. 实验矩阵

### 3.1 主矩阵（ALFWorld + Qwen3-8B-Instruct）

| 实验 | 目的 | 命令 |
|---|---|---|
| AgentOPSD × 3 seeds | 主结果 + 可复现性 | `SEEDS="0 1 2" LAM_SWEEP="0.5" bash scripts/run_stability_matrix.sh` |
| GRPO 对照 × 1~2 seeds | 判断整形是否带来稳定增益 | `SEEDS="0 1" LAM_SWEEP="0.5" ... bash scripts/train.sh --disable-credit`（或设 `AGENTOPSD_ENABLE=0`） |
| λ 敏感性 | 复现论文 Figure 3 | `LAM_SWEEP="0.5 0.25 0.1 0.01"` |
| 续训一致性 | 验收第 1 节第 5 条 | 训练到 40 步 kill → 同命令续训 → 对比 40~80 步曲线 |
| 卡数鲁棒性 | 2 卡 vs 4 卡 | `--gpus 2,3` 与默认 4 卡各跑一个 seed |
| 长 horizon 压力 | 验证长轨迹稳定性 | `MAX_STEPS=50`（默认）；可另跑 `MAX_STEPS=80` 观察信用分布 |

### 3.2 可选扩展

- WebShop / Search-QA 复跑（数据环境步骤见 03 文档），验证方法跨环境稳定性。
- Qwen2.5-7B-Instruct 复现论文 89.1%（模型/数据环境完全同构，仅改 `MODEL_NAME`）。

## 4. 执行流程

```text
1. smoke test       bash scripts/smoke_test.sh        # 2卡2步，验证链路通
2. 单跑主实验       bash scripts/train.sh             # 150 步，观察曲线
3. 断点中断/续训    手动 kill + 同命令重跑             # 验证续训一致性
4. 矩阵跑批         run_stability_matrix.sh           # seeds × λ
5. 汇总报告         stability_report.py --root logs   # 表格 + 告警
6. 人工复核         对照第 1 节 6 条逐项打勾
```

## 6. 判定示例

✅ 稳定：3 个 seed 终值 84/85/85，熵从 1.2 平滑降到 0.35，40 步 kill 后续训曲线与连续训练误差 <1%，credit 乘子均值稳定在 ~1.0、范围 [0.8,1.2]。

❌ 不稳定：成功率 60→85→70→80 大幅振荡；某 seed 在 70 步后 loss 出现 NaN；λ=0.25 与 λ=0.5 行为完全相反；续训后曲线整体平移。
