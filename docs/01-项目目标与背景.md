# 项目目标与背景

## 1. 这个项目要做什么

**目标：实测 AgentOPSD 在 8B 模型上的训练稳定性。**

具体来说：

- 以 **Qwen3-8B-Instruct**（默认，可通过 `MODEL_NAME` 换成 `Qwen2.5-7B-Instruct` 等）为策略模型，在 **ALFWorld**（默认）/ WebShop / Search-QA 三个多轮智能体环境上运行 AgentOPSD 训练。
- 验证训练过程的**稳定性**：成功率曲线平滑收敛、策略熵不崩塌、teacher–student gap 不振荡、无 NaN/发散、不同随机种子可复现、断点续训结果与连续训练一致。
- 提供可复现的工程链路：数据集获取 → 模型下载 → 训练（2~4 张 A800，第 2/3/4/5 卡）→ 评测 → 断点续训 → 稳定性报告。
- 所有环境依赖用 **uv** 维护，服务器端复用已有的 `CUDA-12-conda` 环境（vllm、flash-attn、deepspeed、IPC）。

## 2. AgentOPSD 是什么

AgentOPSD（*Recursive Self-Distillation for Agentic Reinforcement Learning*，arXiv:2608.05987）是一种**无 critic、递归的 turn 级信用分配**方法，用于长程多轮智能体强化学习。

核心问题（也是本项目最关键的着眼点）：

> 基于可验证奖励（RLVR）的 GRPO 只构造**轨迹级优势**并广播到所有 token。长程多轮任务中，最终结果往往由少数几个**关键决策**决定，均匀广播无法区分关键轮次与常规操作。

AgentOPSD 的做法：

1. 把 token 级 teacher–student 对数概率差聚合成 **turn 级证据**；
2. 在 log-odds 空间里对每条轨迹做**递归贝叶斯信念更新**，得到“这一轮把最终成功的估计改动了多少”（边际信念修订 ΔB）；
3. 用 ΔB 对 GRPO 的轨迹级优势做**有界整形**，让关键轮次获得更大、非关键轮次获得更小的更新权重。

方法的详细推导、公式和伪代码见 [02-AgentOPSD方法与奖励信用分配](02-AgentOPSD方法与奖励信用分配.md)。

## 3. 代码现状与本仓库的角色

AgentOPSD 官方仓库（`ZethWang/AgentOPSD`）目前只有 README，训练代码标注 “Code coming soon”。官方实现基于 **SDAR**（ZJU-REAL，第一个把 Agentic RL 与 OP(S)D 统一的开源框架，基于 verl/verl-agent）。

因此本仓库：

- **不 fork 整个 SDAR**，而是把 SDAR 作为基座（`vendor/SDAR`，由 `scripts/setup_server.sh` 克隆，gitignore 排除，不进入版本库）；
- **独立实现 AgentOPSD 核心算法**（`agentopsd/credit.py`，纯 PyTorch，含单元测试）；
- 通过一个**最小的训练钩子**（`agentopsd/trainer/patch.py`）把信用整形注入 SDAR 的 GRPO 训练循环，不改动 SDAR 源码；
- 训练入口 `agentopsd/trainer/main_agentopsd.py` 与 SDAR 的 `main_skillsd` 结构一致（teacher 前向、skill 检索、环境 worker 全部复用），只把"额外蒸馏损失"去掉、把"优势"换成 AgentOPSD 整形后的优势。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| RLVR | Reinforcement Learning with Verifiable Rewards，可验证奖励强化学习 |
| GRPO | Group Relative Policy Optimization，组相对策略优化（轨迹级优势） |
| OPSD | On-Policy Self-Distillation，在线自蒸馏（teacher–student gap） |
| SDAR | Self-Distilled Agentic RL，在 GRPO 上叠加门控自蒸馏损失的框架 |
| teacher 分支 | 训练时把检索到的技能拼进上下文的前向分支（特权信息，推理时不用） |
| turn | 智能体与环境交互的一轮：动作 + 环境反馈 |
| 轨迹 (trajectory) | 从任务开始到结束的完整多轮序列 |
| B0 | 组成功率先验 = 组内成功轨迹比例（被裁剪到 [ε0, 1−ε0]） |
| ΔB | 边际信念修订：本轮的信念值减上一轮 |
| Ã | AgentOPSD 整形后的 turn 级优势 |
